# Book2Speech for macOS and Windows

Turn any book into an audiobook and listen on your computer: your library,
bookmarks and place in every book follow your account between phone, tablet,
computer and the web.

**Download:** https://www.book2speech.com/download

| | |
| --- | --- |
| Mac (Apple Silicon) | [Book2Speech-mac-arm64.dmg](https://github.com/Book2Speech/book2speech-desktop/releases/latest/download/Book2Speech-mac-arm64.dmg) |
| Mac (Intel) | [Book2Speech-mac-x64.dmg](https://github.com/Book2Speech/book2speech-desktop/releases/latest/download/Book2Speech-mac-x64.dmg) |
| Windows | coming soon |

The Mac apps are signed with a Developer ID and notarized by Apple. Open the
`.dmg` and drag Book2Speech into Applications. SHA-256 checksums are attached
to every release.

This repository only hosts the installers; there is no source code here.
Questions or feedback: founder@book2speech.com
